About PixelForge

A gaming hub built by three students who wanted to understand the web from the ground up.

Our story

From class project to gaming hub

PixelForge started as a Front-End Basics assignment. We chose gaming because it is what we talk about between lectures anyway.

Every assignment added something new: Bootstrap layouts, JavaScript forms, an interactive lab, jQuery effects and now a complete multilingual website.

Our journey

  1. HTML & CSSSix pages, one shared dark palette, published on GitHub Pages.
  2. Bootstrap & responsive layoutGrids, carousel and media queries for phones, tablets and desktops.
  3. JavaScriptForm validation, FAQ accordion, pop-up and a live clock.
  4. Player LabDOM events, objects, arrays, sound and animation.
  5. jQueryLive search, autocomplete, counters, lazy images and notifications.

What we value
