About PixelForge

PixelForge started as a class project for the Front-End Basics assignment. We wanted a site about something we actually care about — gaming — built without any framework, so we'd really understand HTML and CSS.

Our Story

  1. Chose gaming as our shared topic and split the six pages between three members.
  2. Built the HTML structure for every page — headings, lists, tables, forms.
  3. Designed one shared dark-mode stylesheet with a neon color palette.
  4. Tested every navigation link and fixed broken image paths.
  5. Published the finished site on GitHub Pages.

Our Values

  • Honesty — reviews and rankings with no sponsored bias
  • Consistency — the same palette and layout on every page
  • Collaboration — three students, one unified gaming hub
